# Zeppelin + Spark + Flink — Local Practice Setup

A one-script setup to run Apache Spark and Apache Flink inside Apache Zeppelin notebooks — with **Scala, Python, Java, and SQL** support — all in **local mode** on your laptop. No cluster required.

---

## What You Get

| Component       | Version  | Notes                                      |
|-----------------|----------|--------------------------------------------|
| Apache Zeppelin | 0.12.0   | Notebook UI at http://localhost:8080       |
| Apache Spark    | 3.5.1    | via `pyspark` pip package                  |
| Apache Flink    | 1.17.2   | via `apache-flink` pip package             |
| Java            | 11       | Required (Flink 1.17 + Scala compatibility)|

### Languages supported per engine

| Engine | Scala | Python | SQL | Java |
|--------|-------|--------|-----|------|
| Spark  | `%spark` | `%pyspark` | `%spark.sql` | `%java` (JShell) |
| Flink  | `%flink` | `%flink.pyflink` | `%flink.bsql` / `%flink.ssql` | via `%flink` (Scala) |

---

## Prerequisites

| Tool        | Version       | Install                              |
|-------------|---------------|--------------------------------------|
| Java        | 11            | [Corretto 11](https://aws.amazon.com/corretto/) or `brew install openjdk@11` |
| Python      | 3.11          | `brew install python@3.11`           |
| Python      | 3.10          | `brew install python@3.10`           |
| curl        | any           | pre-installed on macOS/Linux         |

> **Why two Python versions?**
> Spark works with Python 3.11. Flink 1.17's pip package requires Python < 3.11, so it uses a separate 3.10 venv.

## Quick Start

```bash
git clone https://github.com/YOUR_USERNAME/zeppelin-spark-flink-local.git
cd zeppelin-spark-flink-local

# Run setup (downloads Zeppelin, creates venvs, installs packages, patches config)
bash scripts/setup.sh

# Start Zeppelin
bash scripts/start.sh
```

Open **http://localhost:8080**, create a notebook, and start writing paragraphs.

```bash
# Stop Zeppelin
bash scripts/stop.sh
```

## Example Paragraphs

### Spark — Scala
```scala
// %spark
val data = sc.parallelize(1 to 100)
println(data.sum())
```

### Spark — Python
```python
# %pyspark
data = sc.parallelize(range(1, 101))
print(data.sum())
```

### Spark — SQL
```sql
-- %spark.sql
SELECT 'hello spark' AS greeting
```

### Flink — Scala (Batch)
```scala
// %flink
val data = benv.fromElements(1, 2, 3, 4, 5)
data.reduce(_ + _).print()
```

### Flink — Python
```python
# %flink.pyflink
from pyflink.table import EnvironmentSettings, TableEnvironment
t_env = TableEnvironment.create(EnvironmentSettings.in_batch_mode())
print("PyFlink ready")
```

### Flink — SQL (Batch)
```sql
-- %flink.bsql
SELECT 1 + 1 AS result
```

## How It Works

```
zeppelin-spark-flink-local/
├── scripts/
│   ├── setup.sh             # Main setup script
│   ├── patch-interpreter.py # Patches interpreter.json
│   ├── start.sh             # Start Zeppelin daemon
│   └── stop.sh              # Stop Zeppelin daemon
└── README.md

# After setup, Zeppelin is downloaded alongside this repo:
zeppelin-0.12.0-bin-all/
├── zeppelin-pyenv/          # Python 3.11 venv (Spark)
│   └── lib/python3.11/site-packages/pyspark/   ← SPARK_HOME
├── flink-pyenv/             # Python 3.10 venv (Flink)
│   └── lib/python3.10/site-packages/pyflink/   ← FLINK_HOME
└── conf/
    ├── zeppelin-env.sh      # Generated by setup.sh
    └── interpreter.json     # Patched by setup.sh
```

### Extra jars patched into Flink (required by Zeppelin 0.12.0)
- `flink-sql-client-1.17.2.jar` — moved from `opt/` to `lib/`
- `flink-python-1.17.2.jar` — moved from `opt/` to `lib/`
- `flink-table-api-scala-bridge_2.12-1.17.2.jar` — downloaded from Maven Central
- `flink-streaming-scala_2.12-1.17.2.jar` — downloaded from Maven Central

## Troubleshooting

| Problem | Fix |
|---------|-----|
| Zeppelin won't start | Check `zeppelin-0.12.0-bin-all/logs/zeppelin-*.log` |
| Flink: `/packages cannot be represented as URI` | You're using Java 17+. Set `JAVA_HOME` to Java 11 in `conf/zeppelin-env.sh` |
| Flink: `NoClassDefFoundError` | Re-run `setup.sh` — it downloads and patches the required jars |
| Port 8080 in use | Change `ZEPPELIN_PORT` in `conf/zeppelin-env.sh` then restart |
| Spark paragraph fails | In Zeppelin UI: Interpreter → spark → verify `SPARK_HOME` and `spark.master=local[*]` |
